# Cyberdelic VR

A guided, breath-paced journey inside a kaleidoscopic dome, built with three.js and WebXR.

**Play:** https://sdbishop1221-prog.github.io/cyberdelic-vr/

- **Enter VR** — open the link in your headset's browser (e.g. Meta Quest Browser) and tap Enter VR.
- **Cardboard** — split-screen stereo for a phone viewer, with head tracking.
- **Flat preview** — any screen; drag to look around.

Slow, intense color patterns with no flashing or strobing. Not recommended for people with photosensitive epilepsy; stop if you feel nauseous or dizzy.
